Chapter 1 · Functions and Models

Functions, domains and the main families

A function is a rule: you put in \(x\) and get exactly one output \(f(x)\). The domain is every \(x\) you are allowed to put in. Almost every calculus problem quietly starts with: where does this function exist?

How to find a domain

  1. Start with all real numbers.
  2. Remove any \(x\) that makes a denominator 0.
  3. Keep only \(x\) that make the inside of an even root \(\ge 0\).
  4. Keep only \(x\) that make the inside of a log \(> 0\).
  5. Combine all the conditions (they must all hold at once).

Worked example

Find the domain of \(f(x)=\dfrac{\sqrt{x+2}}{x-3}\).

  1. Root: \(x+2\ge0\Rightarrow x\ge-2\).
  2. Denominator: \(x-3\ne0\Rightarrow x\ne3\).
  3. Both together: \(x\ge-2\) but not 3, so the domain is \([-2,3)\cup(3,\infty)\).

The families you need to recognise on sight

Even and odd. Substitute \(-x\) and simplify. If you get \(f(x)\) back it is even (mirror in the y-axis, like \(x^2\)). If you get \(-f(x)\) it is odd (rotate 180° about the origin, like \(x^3\)). Example: \(f(x)=x^3-x\Rightarrow f(-x)=-x^3+x=-f(x)\), odd.
Trap: a log needs its input strictly positive (\(>0\)), a square root allows 0 (\(\ge0\)).

Transformations: moving a graph

You rarely graph from scratch. Most functions are a basic shape that has been shifted, stretched or flipped. Learn four moves and you can sketch \(y=a\,f\big(b(x-h)\big)+k\) instantly.

How to use it

  1. Name the base function (\(x^2,\sqrt x,|x|,\sin x,\dots\)).
  2. Inside changes act on \(x\) and work backwards: \(x-h\) moves right by \(h\); \(bx\) squeezes horizontally by \(b\); \(-x\) flips left-right.
  3. Outside changes act on \(y\) normally: \(+k\) moves up; \(a\cdot\) stretches vertically; a negative \(a\) flips upside down.
  4. Do the horizontal moves first, then the vertical ones. Track one key point, like the vertex or the start of \(\sqrt x\).

Worked example

Sketch \(y=-2\sqrt{x+1}+3\).

  1. Base \(\sqrt x\): starts at \((0,0)\), rises to the right.
  2. \(x+1\) inside: shift left 1. Start point \((-1,0)\).
  3. \(\times2\): twice as steep. The minus sign flips it, so it now falls to the right.
  4. \(+3\): lift up 3. Start point \((-1,3)\), heading down-right. Domain \(x\ge-1\), range \(y\le3\).
Trap: \(f(x+1)\) moves the graph left, and \(f(2x)\) makes it narrower. Inside changes do the opposite of what they look like.

Composition: one function inside another

\((f\circ g)(x)=f\big(g(x)\big)\): run \(x\) through \(g\), then feed the result to \(f\). Learning to see the inside and the outside now is what makes the chain rule easy in chapter 3.

How to use it

  1. To evaluate \(f(g(a))\): compute \(g(a)\) first, then put that number into \(f\).
  2. To find the formula \(f(g(x))\): write \(f\)'s formula and replace every \(x\) with the whole of \(g(x)\) in brackets.
  3. To break a function apart: ask "what is computed last?" That is the outside \(f\); everything it acts on is the inside \(g\).

Worked example

Break \(h(x)=\sqrt{x^2+1}\) into \(f(g(x))\), then find \(h\) using \(f\) and \(g\) at \(x=2\).

  1. The last operation is the square root, so the outside is \(f(u)=\sqrt u\).
  2. What the root acts on is the inside: \(g(x)=x^2+1\).
  3. Check: \(f(g(x))=\sqrt{x^2+1}\) ✓.
  4. At 2: \(g(2)=5\), then \(f(5)=\sqrt5\).
Trap: order matters. With \(f(x)=x^2\), \(g(x)=3x-1\): \(f(g(x))=(3x-1)^2\) but \(g(f(x))=3x^2-1\).

Exponential functions and the number e

\(a^x\) multiplies by \(a\) every time \(x\) goes up by 1, so it grows (\(a>1\)) or decays (\(0

The rules

  1. \(a^{x+y}=a^xa^y\), \(a^{x-y}=\dfrac{a^x}{a^y}\), \((a^x)^y=a^{xy}\), \((ab)^x=a^xb^x\).
  2. \(a^0=1\), \(a^{-x}=\dfrac1{a^x}\), and \(a^x>0\) for every \(x\).
  3. To solve \(a^{\text{something}}=\text{number}\): write both sides with the same base, or take \(\ln\) of both sides.

Worked example

Solve \(4^x=8\).

  1. Both are powers of 2: \(4=2^2\), \(8=2^3\).
  2. \((2^2)^x=2^3\Rightarrow 2^{2x}=2^3\).
  3. Same base, so the powers match: \(2x=3\Rightarrow x=\tfrac32\).
Trap: \(2^x\) (exponential, variable on top) and \(x^2\) (power, variable at the bottom) are different animals with different derivatives.

Inverse functions and logarithms

An inverse undoes a function: if \(f\) sends 3 to 8, then \(f^{-1}\) sends 8 back to 3. The logarithm is the inverse of the exponential, which is why \(\ln\) and \(e^x\) cancel each other out.

How to use it

  1. Check \(f\) is one-to-one: every horizontal line hits the graph at most once.
  2. Write \(y=f(x)\) and solve for \(x\) in terms of \(y\).
  3. Swap the letters: that formula is \(f^{-1}(x)\).
  4. Log laws: \(\ln(xy)=\ln x+\ln y\), \(\ln\tfrac xy=\ln x-\ln y\), \(\ln x^r=r\ln x\), \(\ln e^x=x\), \(e^{\ln x}=x\), \(\log_ax=\tfrac{\ln x}{\ln a}\).

Worked example

Find the inverse of \(f(x)=\ln(x-2)\).

  1. Write \(y=\ln(x-2)\).
  2. Undo the log by raising \(e\) to both sides: \(e^y=x-2\).
  3. Solve: \(x=e^y+2\).
  4. Swap: \(f^{-1}(x)=e^x+2\). Check: \(f(f^{-1}(x))=\ln(e^x)=x\) ✓.
Trap: \(f^{-1}(x)\) is the inverse, not \(\tfrac1{f(x)}\). And \(\ln(a+b)\ne\ln a+\ln b\): the log laws work for products, not sums.

Chapter 2 · Limits and Derivatives

The idea of a limit

\(\displaystyle\lim_{x\to a}f(x)=L\) means: as \(x\) gets close to \(a\) from both sides, but never equal to \(a\), the values \(f(x)\) get close to \(L\). What happens exactly at \(a\) does not matter. \(f(a)\) can be different, or not exist at all.

How to estimate a limit

  1. Table: plug in \(x\) values closer and closer to \(a\) from both sides (like \(0.9, 0.99, 0.999\) and \(1.1, 1.01, 1.001\)).
  2. Graph: follow the curve toward \(x=a\) from the left and from the right.
  3. If both sides head to the same height \(L\), the limit is \(L\). The next lessons show how to get it exactly.

Worked example

Estimate \(\displaystyle\lim_{x\to1}\frac{x^2-1}{x-1}\).

  1. Left side: \(f(0.9)=1.9\), \(f(0.99)=1.99\), \(f(0.999)=1.999\).
  2. Right side: \(f(1.1)=2.1\), \(f(1.01)=2.01\), \(f(1.001)=2.001\).
  3. Both sides approach 2, so the limit is 2. (Exactly: \(\tfrac{(x-1)(x+1)}{x-1}=x+1\to2\).)
Trap: "the limit equals \(f(a)\)" is only true when \(f\) is continuous at \(a\). Never assume it.

One-sided limits, and when limits don't exist

\(\lim_{x\to a^-}\) approaches from the left, \(\lim_{x\to a^+}\) from the right. The two-sided limit exists only if both one-sided limits exist and are equal. There are three classic ways for a limit to fail.

How to use it on a piecewise function

  1. Left limit: use the piece for \(x
  2. Right limit: use the piece for \(x>a\) and substitute \(a\).
  3. Equal: the limit is that number. Different: the limit does not exist.

Worked example

\(f(x)=\begin{cases}x+1 & x<2\\ x^2-1 & x\ge2\end{cases}\). Find \(\lim_{x\to2}f(x)\).

  1. Left: \(\lim_{x\to2^-}(x+1)=3\).
  2. Right: \(\lim_{x\to2^+}(x^2-1)=3\).
  3. Equal, so \(\lim_{x\to2}f(x)=3\). (If the right piece were \(x^2\), the right limit would be 4 and the limit would not exist.)
Trap: writing "\(=\infty\)" describes how the limit fails. It is not a number, so the limit still does not exist.

Limit laws and direct substitution

Limits follow arithmetic: the limit of a sum is the sum of the limits, and the same for differences, products, constant multiples, powers, roots and quotients (if the bottom limit isn't 0). The result: for polynomials, rational functions, roots, trig, \(e^x\) and \(\ln x\) at points in their domain, you can just plug in.

How to use it: always try substitution first

  1. Substitute \(x=a\).
  2. You get a normal number: that's the answer.
  3. You get \(\tfrac{\text{nonzero}}{0}\): it blows up (\(\pm\infty\)). Check the signs from each side.
  4. You get \(\tfrac00\): indeterminate. Simplify first (next lesson).

Worked example (last year's Q2)

(1) \(\displaystyle\lim_{x\to-5}\frac{x+2}{x+3}\) and (2) \(\displaystyle\lim_{x\to4}\ln(x^2-9)\).

  1. (1) Substitute: \(\dfrac{-5+2}{-5+3}=\dfrac{-3}{-2}=\dfrac32\). The denominator isn't 0, so done.
  2. (2) \(\ln\) is continuous where its input is positive: \(4^2-9=7>0\).
  3. So the limit is \(\ln7\).
Trap: \(\tfrac00\) is not 0 and not "undefined". It means "this needs more work".

Fixing 0/0: factor and conjugate

Getting \(\tfrac00\) at \(x=a\) almost always means the top and bottom share a hidden factor \((x-a)\). Cancel it and the hole disappears. The simplified function equals the original everywhere except at \(a\), so it has the same limit.

Three methods

  1. Factor (polynomials): factor top and bottom, cancel \((x-a)\), substitute again.
  2. Conjugate (square roots): multiply top and bottom by \(\sqrt{\cdot}+k\), use \((A-B)(A+B)=A^2-B^2\) on the top, cancel, substitute.
  3. Common denominator (fractions inside fractions): combine into one fraction, simplify, cancel.

Worked example 1 (last year's Q4(1))

\(\displaystyle\lim_{x\to2}\frac{x^2-5x+6}{x-2}\)

  1. Substitute: \(\tfrac{4-10+6}{0}=\tfrac00\). Simplify.
  2. Factor: \(x^2-5x+6=(x-2)(x-3)\).
  3. Cancel: \(\dfrac{(x-2)(x-3)}{x-2}=x-3\) for \(x\ne2\).
  4. Substitute: \(2-3=-1\).

Worked example 2 (last year's Q4(2))

\(\displaystyle\lim_{x\to0}\frac{\sqrt{x+16}-4}{x}\)

  1. Substitute: \(\tfrac{4-4}{0}=\tfrac00\).
  2. Multiply top and bottom by the conjugate \(\sqrt{x+16}+4\).
  3. Top: \((\sqrt{x+16})^2-4^2=x+16-16=x\).
  4. So \(\dfrac{x}{x(\sqrt{x+16}+4)}=\dfrac1{\sqrt{x+16}+4}\).
  5. Substitute: \(\dfrac1{4+4}=\dfrac18\).
Trap: you may cancel \((x-a)\) only because in a limit \(x\ne a\). Write the limit sign on every line until you substitute.

The squeeze theorem and sin θ / θ

When a function wiggles too much to simplify, trap it between two simpler functions that go to the same limit. It has nowhere else to go. The same idea proves the most important trig limit, \(\tfrac{\sin\theta}{\theta}\to1\).

How to use the squeeze theorem

  1. Find the bounded part: \(-1\le\sin(\text{anything})\le1\), \(-1\le\cos(\text{anything})\le1\).
  2. Multiply the inequality by the rest of the function. It must be \(\ge0\) (like \(x^2\) or \(|x|\)) so the signs don't flip.
  3. Check both bounds have the same limit \(L\).
  4. Conclude: the squeezed function also goes to \(L\).

Worked example 1 (last year's Q4(3))

\(\displaystyle\lim_{x\to0}x^2\cos\tfrac1x\)

  1. \(-1\le\cos\tfrac1x\le1\) for all \(x\ne0\).
  2. Multiply by \(x^2\ge0\): \(-x^2\le x^2\cos\tfrac1x\le x^2\).
  3. \(\lim_{x\to0}(-x^2)=0\) and \(\lim_{x\to0}x^2=0\).
  4. By the squeeze theorem the limit is \(0\).

Worked example 2 (last year's Q2(3))

\(\displaystyle\lim_{x\to0}\frac{\sin2x}{\sin5x}\)

  1. Make the pattern \(\tfrac{\sin u}{u}\) appear: \(\dfrac{\sin2x}{\sin5x}=\dfrac{\sin2x}{2x}\cdot\dfrac{5x}{\sin5x}\cdot\dfrac{2x}{5x}\).
  2. As \(x\to0\): \(\tfrac{\sin2x}{2x}\to1\) and \(\tfrac{5x}{\sin5x}\to1\).
  3. What's left: \(\tfrac{2x}{5x}=\tfrac25\). The limit is \(\tfrac25\).
Trap: \(\tfrac{\sin\theta}{\theta}\to1\) only works in radians and only when the angle inside \(\sin\) matches the bottom exactly.

Asymptotes: limits involving infinity

A vertical asymptote \(x=a\) is where \(f\) blows up to \(\pm\infty\). A horizontal asymptote \(y=L\) is the height \(f\) settles to as \(x\to\pm\infty\). Together they give the skeleton of a graph.

How to find them

  1. Vertical: find where the denominator is 0 but the numerator isn't (if both are 0, it's a hole instead). Check the sign on each side to see \(+\infty\) or \(-\infty\).
  2. Horizontal (rational functions): divide top and bottom by the highest power of \(x\) in the denominator. Every \(\tfrac{c}{x^n}\to0\).
  3. Shortcut: equal degrees → ratio of leading coefficients; top smaller → 0; top bigger → no horizontal asymptote.
  4. Also: \(e^x\to0\) as \(x\to-\infty\), and \(\ln x\to-\infty\) as \(x\to0^+\).

Worked example

\(\displaystyle\lim_{x\to\infty}\frac{3x^2-x}{5x^2+2}\)

  1. Divide every term by \(x^2\): \(\dfrac{3-\tfrac1x}{5+\tfrac2{x^2}}\).
  2. As \(x\to\infty\): \(\tfrac1x\to0\) and \(\tfrac2{x^2}\to0\).
  3. The limit is \(\tfrac35\), so \(y=\tfrac35\) is a horizontal asymptote.
Trap: a graph can cross its horizontal asymptote (for example \(\tfrac{\sin x}x\)). It can never cross a vertical one.

Continuity

\(f\) is continuous at \(a\) if you can draw through \(x=a\) without lifting your pen. Precisely, three things must hold: \(f(a)\) is defined, \(\lim_{x\to a}f(x)\) exists, and they are equal.

How to check continuity at a point

  1. Compute \(f(a)\) using the piece that includes \(x=a\).
  2. Compute the left limit and the right limit using the correct pieces.
  3. All three equal: continuous. Otherwise say which condition fails.
  4. To make it continuous (find a constant \(k\)): set left limit = right limit and solve for \(k\).

Worked example (last year's Q3)

\(f(x)=\begin{cases}x-1 & x<0\\ -1 & x=0\\ \cos(\pi-x) & x>0\end{cases}\). Is \(f\) continuous at 0?

  1. Value: \(f(0)=-1\).
  2. Left: \(\lim_{x\to0^-}(x-1)=-1\).
  3. Right: \(\lim_{x\to0^+}\cos(\pi-x)=\cos\pi=-1\).
  4. \(\lim_{x\to0}f(x)=-1=f(0)\), so \(f\) is continuous at 0 by the definition.
Trap: the question says "using the definition", so write all three checks. A correct answer with no justification loses marks.

The Intermediate Value Theorem

A continuous function can't skip values. If it goes from \(f(a)\) to \(f(b)\), it passes through every value in between. This is how you prove an equation has a solution without solving it.

How to use it to prove a root exists

  1. Say why \(f\) is continuous on \([a,b]\) (polynomial, sum of continuous functions, …).
  2. Compute \(f(a)\) and \(f(b)\).
  3. Show \(N\) (usually 0) is between them. For roots this means a sign change.
  4. Conclude: by the IVT there is a \(c\in(a,b)\) with \(f(c)=N\).

Worked example

Show \(x^3+x-1=0\) has a solution in \((0,1)\).

  1. \(f(x)=x^3+x-1\) is a polynomial, so it is continuous on \([0,1]\).
  2. \(f(0)=-1<0\) and \(f(1)=1>0\).
  3. 0 is between \(-1\) and 1.
  4. By the IVT, some \(c\in(0,1)\) has \(f(c)=0\).
Trap: without continuity it fails: \(\tfrac1x\) is \(-1\) at \(x=-1\) and \(1\) at \(x=1\) but never 0. Last year's Q1(2) option A was the IVT.

The derivative: slope of the tangent

The derivative \(f'(a)\) is the slope of the curve at a single point. You get it as the limit of slopes of secant lines as the second point slides into the first. It is also the instantaneous rate of change, like a speedometer reading.

How to use the definition

  1. Write \(f(a+h)\) and expand it.
  2. Subtract \(f(a)\) and simplify. Every remaining term should contain \(h\).
  3. Divide by \(h\) (cancel it).
  4. Let \(h\to0\). That number is \(f'(a)\).
  5. Tangent line: \(y-f(a)=f'(a)(x-a)\).

Worked example

Use the definition to find \(f'(3)\) for \(f(x)=x^2\), then the tangent line at \(x=3\).

  1. \(f(3+h)=9+6h+h^2\).
  2. \(f(3+h)-f(3)=6h+h^2\).
  3. Divide by \(h\): \(6+h\).
  4. \(h\to0\): \(f'(3)=6\).
  5. Tangent: \(y-9=6(x-3)\), so \(y=6x-9\).
Trap: don't let \(h\to0\) before cancelling \(h\), or you get \(\tfrac00\) again.

Where derivatives fail

\(f'(x)\) is itself a function: the slope of \(f\) at every \(x\). Differentiable implies continuous, but not the other way round. A graph can be unbroken and still have no single slope at a point.

How to use it

  1. Reading \(f'\) from a graph of \(f\): rising means \(f'>0\), falling means \(f'<0\), flat (peak or valley) means \(f'=0\).
  2. Checking differentiability at \(a\): compute the slope limit from the left and from the right. They must be equal and finite.
  3. Not continuous at \(a\) means automatically not differentiable at \(a\).

Worked example

Is \(f(x)=|x|\) differentiable at 0?

  1. Slope quotient: \(\dfrac{f(0+h)-f(0)}{h}=\dfrac{|h|}{h}\).
  2. For \(h>0\) it is 1; for \(h<0\) it is −1.
  3. The one-sided limits differ, so \(f'(0)\) does not exist, even though \(f\) is continuous at 0.
Last year's Q1(1): continuous does not imply differentiable, and a limit existing does not imply continuity. But differentiable ⇒ continuous ⇒ the limit exists, so the true statement was D.

Chapter 3 · Differentiation Rules

Power, sum and exponential rules

Instead of the limit definition, use rules. The power rule \((x^n)'=nx^{n-1}\) works for every power, including roots and negative powers once you rewrite them. And \(e^x\) is the function that is its own derivative.

How to use it

  1. Rewrite first: \(\sqrt x=x^{1/2}\), \(\tfrac1{x^3}=x^{-3}\), \(\tfrac{1}{\sqrt x}=x^{-1/2}\).
  2. Bring the power down in front, then subtract 1 from the power.
  3. Constants multiply through: \((5x^4)'=20x^3\). A lone constant has derivative 0.
  4. Sums: differentiate term by term.
  5. \((e^x)'=e^x\) and \((a^x)'=a^x\ln a\).

Worked example (last year's Q2(4) and Q2(6))

Differentiate \(g(t)=3t^{-1/4}\) and \(f(x)=2x+e^{3.6}\).

  1. \(g'(t)=3\cdot\left(-\tfrac14\right)t^{-1/4-1}=-\tfrac34t^{-5/4}\).
  2. \(e^{3.6}\) has no \(x\) in it: it is just a number, so its derivative is 0.
  3. \(f'(x)=2\).
Trap: \(e^{3.6}\), \(\pi^2\), \(\ln5\) are constants. Their derivative is 0, not "themselves".

Product and quotient rules

The derivative of a product is not the product of the derivatives. Picture a rectangle with sides \(u\) and \(v\). When both sides grow a little, the area grows by two strips, \(u\,dv\) and \(v\,du\), plus a tiny corner that vanishes in the limit.

How to use them

  1. Product: \((uv)'=u'v+uv'\). Derivative of the first times the second, plus the first times the derivative of the second.
  2. Quotient: \(\left(\dfrac uv\right)'=\dfrac{u'v-uv'}{v^2}\). "Low d-high minus high d-low, over low squared."
  3. Simplify first when you can: \(\tfrac{x^2+x}{x}=x+1\) needs no quotient rule.

Worked example

Differentiate \(f(x)=x^2e^x\) and \(g(x)=\dfrac{x}{x^2+1}\).

  1. Product: \(u=x^2,\ v=e^x\), so \(f'=2x\,e^x+x^2e^x=xe^x(x+2)\).
  2. Quotient: \(u=x,\ u'=1,\ v=x^2+1,\ v'=2x\).
  3. \(g'=\dfrac{1\cdot(x^2+1)-x\cdot2x}{(x^2+1)^2}=\dfrac{1-x^2}{(x^2+1)^2}\).
Trap: in the quotient rule the order matters because of the minus sign: top's derivative comes first.

Derivatives of trig functions

Watch the slope of \(\sin x\) as you move along it: it traces out \(\cos x\) exactly. Where \(\sin\) peaks, its slope is 0, and that is where \(\cos\) crosses zero.

How to use them

  1. Memorise: \((\sin x)'=\cos x\), \((\cos x)'=-\sin x\), \((\tan x)'=\sec^2x\).
  2. And: \((\sec x)'=\sec x\tan x\), \((\csc x)'=-\csc x\cot x\), \((\cot x)'=-\csc^2x\). The "co" ones all get a minus.
  3. Repeated derivatives cycle every 4: \(\sin\to\cos\to-\sin\to-\cos\to\sin\). For the \(n\)th derivative, use \(n\bmod4\).
  4. These formulas only hold in radians.

Worked example (last year's Q2(8))

\(u(x)=\cos x\). Find \(u^{(17)}\!\left(\tfrac\pi3\right)\).

  1. The cycle for \(\cos\): \(u'=-\sin x,\ u''=-\cos x,\ u'''=\sin x,\ u^{(4)}=\cos x\).
  2. \(17=4\cdot4+1\), so \(u^{(17)}=u'=-\sin x\).
  3. \(-\sin\tfrac\pi3=-\tfrac{\sqrt3}2\).

Worked example (last year's Q2(5))

\(f(x)=\tfrac12\cot x\). Find \(f'(x)\).

  1. Constant multiple: \(f'=\tfrac12(\cot x)'\).
  2. \((\cot x)'=-\csc^2x\), so \(f'(x)=-\tfrac12\csc^2x\).
Trap: the minus in \((\cos x)'=-\sin x\) is the most-lost sign in the whole course.

The chain rule

For a composition \(y=f(g(x))\), rates multiply. If \(u\) changes 2 times as fast as \(x\), and \(y\) changes 3 times as fast as \(u\), then \(y\) changes \(2\times3=6\) times as fast as \(x\): \(\dfrac{dy}{dx}=\dfrac{dy}{du}\cdot\dfrac{du}{dx}\).

How to use it

  1. Spot the outside function \(f\) and the inside \(g\) (lesson "Composition").
  2. Differentiate the outside, leaving the inside untouched: \(f'(g(x))\).
  3. Multiply by the derivative of the inside: \(\cdot\,g'(x)\).
  4. Several layers? Peel them one at a time, outside to inside, multiplying as you go.
  5. Useful forms: \((u^n)'=nu^{n-1}u'\), \((e^u)'=e^uu'\), \((\sin u)'=\cos u\cdot u'\), \((\ln u)'=\tfrac{u'}u\).

Worked example 1

\(y=(x^2+1)^5\)

  1. Outside: \((\ )^5\). Inside: \(u=x^2+1\).
  2. Outside derivative: \(5(x^2+1)^4\).
  3. Times inside derivative \(2x\): \(y'=10x(x^2+1)^4\).

Worked example 2 (last year's Q5(2))

\(f(x)=\sin\!\left(\dfrac{x-1}{x+1}\right)\)

  1. Outside: \(\sin(\ )\). Inside: \(u=\dfrac{x-1}{x+1}\).
  2. Inside derivative (quotient rule): \(u'=\dfrac{(x+1)-(x-1)}{(x+1)^2}=\dfrac{2}{(x+1)^2}\).
  3. \(f'(x)=\cos\!\left(\dfrac{x-1}{x+1}\right)\cdot\dfrac{2}{(x+1)^2}\).
Trap: forgetting to multiply by the inside derivative. If there is something other than plain \(x\) inside, there is a chain rule.

Implicit differentiation

Some curves, like circles, can't be written as one \(y=f(x)\). Differentiate the equation as it stands, treating \(y\) as an unknown function of \(x\). Every \(y\)-term picks up a \(y'\) from the chain rule.

How to use it

  1. Apply \(\tfrac{d}{dx}\) to both sides.
  2. \(x\)-terms: as usual. \(y\)-terms: chain rule, \((y^n)'=ny^{n-1}\,y'\).
  3. Mixed terms like \(xy\): product rule, \((xy)'=y+xy'\).
  4. Move all \(y'\) terms to one side, factor out \(y'\), divide.
  5. Plug in the point to get the slope; then \(y-y_0=m(x-x_0)\).

Worked example (last year's Q6)

Tangent line to \(x^2+2y^3=3xy\) at \((1,1)\).

  1. Differentiate: \(2x+6y^2y'=3y+3xy'\).
  2. Collect: \(6y^2y'-3xy'=3y-2x\).
  3. Factor: \(y'(6y^2-3x)=3y-2x\Rightarrow y'=\dfrac{3y-2x}{6y^2-3x}\).
  4. At \((1,1)\): \(y'=\dfrac{3-2}{6-3}=\dfrac13\).
  5. Tangent: \(y-1=\tfrac13(x-1)\), so \(y=\tfrac13x+\tfrac23\).
Trap: \((y^3)'\) is \(3y^2y'\), not \(3y^2\). And \(3xy\) needs the product rule.

Log derivatives and logarithmic differentiation

The slope of \(\ln x\) at \(x\) is \(\tfrac1x\): steep near 0, flatter further out. Logs also turn products into sums and powers into multiplication. That is the trick behind logarithmic differentiation, the only way to handle \(x^{x}\)-type functions.

How to use it

  1. \((\ln u)'=\dfrac{u'}{u}\), \((\ln|x|)'=\dfrac1x\), \((\log_ax)'=\dfrac1{x\ln a}\).
  2. Simplify with log laws before differentiating: \(\ln(x^2\sqrt{x+1})=2\ln x+\tfrac12\ln(x+1)\).
  3. Logarithmic differentiation for \(y=f(x)^{g(x)}\): take \(\ln\): \(\ln y=g(x)\ln f(x)\).
  4. Differentiate both sides: \(\tfrac{y'}y=\dots\) (product rule on the right).
  5. Multiply by \(y\), then substitute \(y\) back.

Worked example (last year's Q5(3))

\(y=x^{\cos x}\)

  1. Take logs: \(\ln y=\cos x\,\ln x\).
  2. Differentiate (product rule): \(\dfrac{y'}{y}=-\sin x\,\ln x+\cos x\cdot\dfrac1x\).
  3. Multiply by \(y\): \(y'=x^{\cos x}\left(\dfrac{\cos x}{x}-\sin x\ln x\right)\).

Worked example (last year's Q5(1))

\(f(x)=\sqrt x\,\ln(x^2+1)\)

  1. Product rule with \(u=\sqrt x\), \(v=\ln(x^2+1)\).
  2. \(u'=\dfrac1{2\sqrt x}\); \(v'=\dfrac{2x}{x^2+1}\) (chain rule).
  3. \(f'(x)=\dfrac{\ln(x^2+1)}{2\sqrt x}+\dfrac{2x\sqrt x}{x^2+1}\).
Trap: \((x^x)'\ne x\cdot x^{x-1}\) (power rule) and \(\ne x^x\ln x\) (exponential rule). With \(x\) in both base and exponent you need logs.

Related rates

When quantities are linked by an equation and they change over time, their rates of change are linked too. Differentiate the equation with respect to time \(t\), and the known rate gives you the unknown one.

How to use it: 6 steps

  1. Draw the situation. Label changing quantities with letters, fixed ones with numbers.
  2. Write what you know and what you want as derivatives (\(\tfrac{dx}{dt}=1\), find \(\tfrac{dy}{dt}\)).
  3. Find an equation linking the variables (Pythagoras, area, volume, similar triangles).
  4. Differentiate with respect to \(t\), using the chain rule on every variable.
  5. Now substitute the numbers for that instant.
  6. Solve, and give units and the meaning of the sign.

Worked example

The 5 m ladder's foot slides out at 1 m/s. How fast is the top falling when the foot is 3 m from the wall?

  1. Equation: \(x^2+y^2=25\). Known: \(x'=1\).
  2. Differentiate in \(t\): \(2x\,x'+2y\,y'=0\).
  3. When \(x=3\): \(y=\sqrt{25-9}=4\).
  4. \(2(3)(1)+2(4)y'=0\Rightarrow y'=-\tfrac34\).
  5. The top is falling at \(0.75\) m/s (negative: \(y\) is decreasing).
Trap: substituting \(x=3\) before differentiating turns \(x\) into a constant with derivative 0, and the answer collapses.

Linear approximation

Zoom in far enough on any smooth curve and it looks like its tangent line. So near \(x=a\): \(f(x)\approx L(x)=f(a)+f'(a)(x-a)\). That turns hard values into easy arithmetic.

How to use it

  1. Pick an easy point \(a\) near the value you want (a perfect square, 0, …).
  2. Compute \(f(a)\) and \(f'(a)\).
  3. Build \(L(x)=f(a)+f'(a)(x-a)\).
  4. Evaluate \(L\) at your \(x\). The differential version is \(dy=f'(x)\,dx\).

Worked example

Estimate \(\sqrt{4.1}\).

  1. \(f(x)=\sqrt x\), \(a=4\): \(f(4)=2\).
  2. \(f'(x)=\dfrac1{2\sqrt x}\Rightarrow f'(4)=\dfrac14\).
  3. \(L(x)=2+\tfrac14(x-4)\).
  4. \(L(4.1)=2+\tfrac14(0.1)=2.025\). The true value is \(2.0248\dots\)
Trap: the approximation is only good near \(a\). Choose \(a\) as close as possible.

Rates of change and exponential growth

Derivatives measure change in the real world: position → velocity → acceleration. And when a quantity grows at a rate proportional to its size, \(\tfrac{dy}{dt}=ky\), the solution is always an exponential, \(y=y_0e^{kt}\).

How to use it

  1. Motion: \(v(t)=s'(t)\), \(a(t)=v'(t)\). Speeding up when \(v\) and \(a\) have the same sign.
  2. Growth/decay: write \(y=y_0e^{kt}\) with \(y_0\) the starting amount.
  3. Find \(k\) from a second data point: \(y_1=y_0e^{kt_1}\Rightarrow k=\dfrac{\ln(y_1/y_0)}{t_1}\).
  4. Half-life (decay): \(t_{1/2}=\dfrac{\ln2}{|k|}\).

Worked example

A culture grows from 100 to 300 bacteria in 2 hours. How many after 5 hours?

  1. \(300=100e^{2k}\Rightarrow e^{2k}=3\Rightarrow k=\tfrac{\ln3}2\approx0.549\).
  2. \(y(5)=100e^{5k}=100\left(e^{2k}\right)^{5/2}=100\cdot3^{2.5}\).
  3. \(\approx 1559\) bacteria.
Trap: use the natural log \(\ln\) to solve for \(k\), and keep \(k\) in "per hour" (or whatever time unit the data uses).

Extreme values and critical numbers

An absolute max is the highest point on the whole interval. A local max is just higher than its neighbours. Extrema can only happen at critical numbers (where \(f'=0\) or \(f'\) doesn't exist) or at the endpoints.

How to use it

  1. Find \(f'(x)\).
  2. Solve \(f'(x)=0\).
  3. Also find where \(f'\) is undefined but \(f\) is defined (corners, cusps).
  4. Those \(x\) values are the critical numbers: the only places a local extremum can be.
  5. Extreme Value Theorem: if \(f\) is continuous on a closed interval \([a,b]\), an absolute max and min are guaranteed.

Worked example

Find the critical numbers of \(f(x)=x^3-3x\) and of \(g(x)=|x|\).

  1. \(f'(x)=3x^2-3=3(x-1)(x+1)\).
  2. \(f'=0\) at \(x=\pm1\). \(f'\) exists everywhere, so the critical numbers are \(-1\) and \(1\).
  3. \(g'(x)\) is \(-1\) for \(x<0\) and \(1\) for \(x>0\), and doesn't exist at 0.
  4. So \(x=0\) is a critical number of \(|x|\) (and it is the minimum).
Trap: \(f'(c)=0\) does not guarantee an extremum: \(x^3\) has \(f'(0)=0\) but keeps rising. And on an open interval like \((0,1)\), \(f(x)=x\) has no max at all.

The closed interval method

On \([a,b]\), the absolute max and min are always among a short list: the endpoints and the critical numbers inside. Evaluate \(f\) at every one of them and compare. No guessing from the picture.

How to use it

  1. Find \(f'(x)\) and the critical numbers.
  2. Throw away critical numbers outside \([a,b]\).
  3. Make a table: \(f\) at each remaining critical number and at \(a\) and \(b\).
  4. Biggest value = absolute max; smallest = absolute min. State both the value and where it happens.

Worked example (last year's Q7)

Absolute max and min of \(f(x)=\dfrac{x^2+3}{1+x}\) on \([0,2]\).

  1. Quotient rule: \(f'(x)=\dfrac{2x(1+x)-(x^2+3)}{(1+x)^2}=\dfrac{x^2+2x-3}{(1+x)^2}\).
  2. Factor: \(\dfrac{(x+3)(x-1)}{(1+x)^2}=0\Rightarrow x=1\) or \(x=-3\). Only \(x=1\) is in \([0,2]\).
  3. Table: \(f(0)=3\), \(f(1)=\tfrac42=2\), \(f(2)=\tfrac73\approx2.33\).
  4. Absolute max \(3\) at \(x=0\); absolute min \(2\) at \(x=1\).
Trap: forgetting the endpoints. Here the maximum is an endpoint.

Rolle's theorem and the Mean Value Theorem

Somewhere between \(a\) and \(b\), the instantaneous slope equals the average slope. If you drive 120 km in 1.5 hours, at some moment your speedometer read exactly 80 km/h.

How to use it

  1. Check condition 1: \(f\) is continuous on \([a,b]\).
  2. Check condition 2: \(f\) is differentiable on \((a,b)\).
  3. Average slope: \(m=\dfrac{f(b)-f(a)}{b-a}\).
  4. Solve \(f'(c)=m\) and keep only \(c\) strictly between \(a\) and \(b\).
  5. Rolle is the special case \(f(a)=f(b)\), which gives \(f'(c)=0\).

Worked example

Find the \(c\) for \(f(x)=x^3-2x^2+x\) on \([0,2]\).

  1. A polynomial is continuous and differentiable everywhere, so the MVT applies.
  2. \(m=\dfrac{f(2)-f(0)}{2-0}=\dfrac{2-0}{2}=1\).
  3. \(f'(c)=3c^2-4c+1=1\Rightarrow c(3c-4)=0\).
  4. \(c=0\) is an endpoint, not inside, so \(c=\tfrac43\).
Last year's Q1(2): with \(f(0)=10\) and \(f(8)=30\) the MVT gives \(f'(c)=\tfrac{30-10}{8}=2.5\). Option B said 2, which is not guaranteed.

Increasing, decreasing and the first derivative test

The sign of \(f'\) is the direction of the graph: positive means going up, negative means going down. A local max is where \(f'\) switches from + to −, and a local min where it switches from − to +.

How to use it

  1. Find \(f'\) and factor it.
  2. Find the critical numbers and mark them on a number line.
  3. Pick a test point in each interval and find the sign of \(f'\) there.
  4. \(+\): increasing on that interval; \(-\): decreasing.
  5. Sign change \(+\to-\): local max; \(-\to+\): local min; no change: neither.

Worked example (last year's Q8)

\(f(x)=x^3-2x^2+x\): critical points, increasing/decreasing, local extrema.

  1. \(f'(x)=3x^2-4x+1=(3x-1)(x-1)\). Critical points: \(x=\tfrac13\), \(x=1\).
  2. Test \(x=0\): \((-1)(-1)=+\). Test \(x=\tfrac12\): \((\tfrac12)(-\tfrac12)=-\). Test \(x=2\): \((5)(1)=+\).
  3. Increasing on \((-\infty,\tfrac13)\) and \((1,\infty)\); decreasing on \((\tfrac13,1)\).
  4. Local max at \(x=\tfrac13\): \(f(\tfrac13)=\tfrac1{27}-\tfrac29+\tfrac13=\tfrac4{27}\).
  5. Local min at \(x=1\): \(f(1)=0\).
Trap: answer with intervals for increasing/decreasing and points (with the value) for extrema. Use test points, not guesses.

Concavity and the second derivative test

\(f''\) tells you how the slope is changing. \(f''>0\): the slope increases, so the curve bends up like a cup ∪ and tangents lie below it. \(f''<0\): it bends down like a cap ∩. An inflection point is where the bending flips.

How to use it

  1. Find \(f''(x)\).
  2. Solve \(f''=0\) (and where \(f''\) is undefined).
  3. Sign chart of \(f''\): \(+\) concave up, \(-\) concave down.
  4. Inflection point where the sign of \(f''\) actually changes (and \(f\) is defined there).
  5. Second derivative test at a critical point \(c\) (\(f'(c)=0\)): \(f''(c)>0\) local min, \(f''(c)<0\) local max, \(f''(c)=0\) no conclusion.

Worked example

\(f(x)=x^3-3x^2\): classify the critical points and find the inflection point.

  1. \(f'=3x^2-6x=3x(x-2)\): critical points 0 and 2.
  2. \(f''=6x-6\).
  3. \(f''(0)=-6<0\): local max \(f(0)=0\). \(f''(2)=6>0\): local min \(f(2)=-4\).
  4. \(f''=0\) at \(x=1\), and the sign changes there: inflection point \((1,-2)\).
Trap: \(f''(c)=0\) does not mean inflection: \(x^4\) has \(f''(0)=0\) but is concave up on both sides.

L'Hôpital's rule

When \(f\) and \(g\) are both 0 at a point, zoom in: each one looks like its tangent line, so \(\tfrac{f}{g}\) behaves like the ratio of their slopes, \(\tfrac{f'}{g'}\). That is L'Hôpital's rule.

How to use it

  1. Substitute first. It must be \(\tfrac00\) or \(\tfrac\infty\infty\); otherwise the rule does not apply.
  2. Differentiate the top and the bottom separately.
  3. Take the limit of \(\tfrac{f'}{g'}\). Still \(\tfrac00\)? Apply again.
  4. Other forms: \(0\cdot\infty\) → rewrite as a fraction; \(\infty-\infty\) → common denominator; \(1^\infty,0^0,\infty^0\) → take \(\ln\) first.

Worked example 1

\(\displaystyle\lim_{x\to0}\frac{1-\cos x}{x^2}\)

  1. Substitute: \(\tfrac{0}{0}\). OK to use L'Hôpital.
  2. \(\dfrac{\sin x}{2x}\): still \(\tfrac00\).
  3. Again: \(\dfrac{\cos x}{2}\to\dfrac12\).

Worked example 2

\(\displaystyle\lim_{x\to0^+}x\ln x\) (form \(0\cdot(-\infty)\))

  1. Rewrite as a fraction: \(\dfrac{\ln x}{1/x}\), form \(\tfrac{-\infty}{\infty}\).
  2. Differentiate top and bottom: \(\dfrac{1/x}{-1/x^2}=-x\).
  3. \(-x\to0\). The limit is \(0\).
Trap: it is not the quotient rule. And using it on a limit that isn't \(\tfrac00\) or \(\tfrac\infty\infty\) gives wrong answers.

Curve sketching

Everything together. Each step adds one piece of information, and after the last step the shape of the graph is forced. Use the slider to build the sketch one layer at a time.

The checklist

  1. Domain. Where is \(f\) defined?
  2. Intercepts. \(y\)-intercept \(f(0)\); \(x\)-intercepts solve \(f(x)=0\).
  3. Symmetry. Even, odd, periodic?
  4. Asymptotes. Vertical and horizontal.
  5. Increasing / decreasing from the sign of \(f'\).
  6. Local max / min from the sign changes.
  7. Concavity and inflection from the sign of \(f''\).
  8. Sketch, joining everything smoothly.

Worked example

Sketch \(f(x)=x^3-3x^2\).

  1. Domain: all real numbers. No symmetry, no asymptotes (it's a polynomial).
  2. Intercepts: \(f(0)=0\); \(x^2(x-3)=0\Rightarrow x=0,3\).
  3. \(f'=3x(x-2)\): increasing on \((-\infty,0)\) and \((2,\infty)\), decreasing on \((0,2)\).
  4. Local max \((0,0)\), local min \((2,-4)\).
  5. \(f''=6x-6\): concave down for \(x<1\), up for \(x>1\); inflection \((1,-2)\).

Optimization

Real problems ask for the biggest or smallest something: area, volume, cost, time. Turn the words into a function of one variable, and it becomes the closed interval method again.

How to use it

  1. Read carefully and draw a picture.
  2. Name the variables. Write the quantity \(Q\) you want to maximize or minimize.
  3. Use the constraint (the fixed amount) to write \(Q\) using one variable.
  4. Find the domain (physical limits like \(0\le x\le6\)).
  5. Find critical numbers and compare with the endpoints (or use the first derivative test).
  6. Answer the question that was asked, with units.

Worked example

From a 12 cm × 12 cm sheet, cut equal squares from the corners and fold an open box. Find the largest volume.

  1. Cut size \(x\). Base \((12-2x)\times(12-2x)\), height \(x\): \(V=x(12-2x)^2\), with \(0\le x\le6\).
  2. \(V'=(12-2x)^2+x\cdot2(12-2x)(-2)=(12-2x)(12-6x)\).
  3. \(V'=0\Rightarrow x=6\) or \(x=2\).
  4. Compare: \(V(0)=0\), \(V(6)=0\), \(V(2)=2\cdot8^2=128\).
  5. The largest volume is \(128\text{ cm}^3\), with \(2\) cm squares cut out.
Trap: answer what was asked (the volume, or the dimensions?) and remember the endpoints.

Newton's method and antiderivatives

Newton's method finds roots: follow the tangent line down to the x-axis to get a better guess, then repeat. Antiderivatives run differentiation backwards: find \(F\) with \(F'=f\). They lead straight into chapter 5.

How to use them

  1. Newton: \(x_{n+1}=x_n-\dfrac{f(x_n)}{f'(x_n)}\). Start near the root and repeat until the digits stop changing.
  2. Antiderivatives: reverse each rule. \(x^n\to\dfrac{x^{n+1}}{n+1}\) (\(n\ne-1\)), \(\tfrac1x\to\ln|x|\), \(e^x\to e^x\), \(\cos x\to\sin x\), \(\sin x\to-\cos x\), \(\sec^2x\to\tan x\).
  3. Always add \(+C\). If you're given a value like \(f(0)=5\), use it to find \(C\).

Worked example

(1) Two Newton steps for \(x^2-2=0\) from \(x_0=3\). (2) Find \(f\) if \(f'(x)=3x^2+2\) and \(f(0)=5\).

  1. \(f'(x)=2x\). \(x_1=3-\dfrac{7}{6}\approx1.8333\).
  2. \(x_2=1.8333-\dfrac{1.8333^2-2}{2(1.8333)}\approx1.4621\). Already close to \(1.4142\).
  3. (2) Reverse the power rule: \(f(x)=x^3+2x+C\).
  4. \(f(0)=C=5\), so \(f(x)=x^3+2x+5\).
Trap: forgetting \(+C\), and \(\int\sin x\,dx=-\cos x+C\) (the minus moves to the other side compared with derivatives).
