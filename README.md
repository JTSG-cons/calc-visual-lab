# Calculus Visual Lab

An interactive study site for Calculus chapters 1–4 (Stewart, *Calculus: Early Transcendentals*, 7th ed.): research-backed study strategies, 12 interactive graphs and a 6-day exam plan.

Static HTML, CSS and JavaScript with no build step. Three.js and KaTeX are in `vendor/`, so the site loads without outside CDNs.

Run locally: `python -m http.server` in this folder, then open http://localhost:8000.
