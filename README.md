# Calculus Visual Lab

An interactive study site for Calculus chapters 1–4 (Stewart, *Calculus: Early Transcendentals*, 7th ed.): research-backed study strategies, 12 interactive graphs and a 6-day exam plan.

Static HTML, CSS and JavaScript with no build step. KaTeX, MathLive (math answer field), JSXGraph (draggable lab graphs), ts-fsrs (spaced review) and the fonts are bundled in `vendor/`, so the site loads without Google Fonts or overseas CDNs. Design: "textbook paper" with a chalkboard dark mode.

Run locally: `python -m http.server` in this folder, then open http://localhost:8000.
